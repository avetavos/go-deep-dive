# Go Deep Dive

**Master the Go language — from first goroutine to production patterns.**

Go is a statically typed, compiled language built for simplicity, reliability, and scale. Written for Go 1.27 (with notes on which release introduced each feature), this course teaches Go on its own terms: no comparisons, no shortcuts — just deep, idiomatic Go from the ground up.

## How to use this course

Work through modules in order. Each lesson contains a runnable playground — the Run button compiles on go.dev with the current Go release (1.27) and falls back to an in-browser interpreter (Go 1.26, older APIs only) when you are offline — a key-point callout, a short quiz, and a progress tracker. You can mark lessons complete as you go — progress is saved locally in your browser.

## Why Go?

Every language trades something away. Knowing what Go gave up is as useful as knowing what it bought.

| What you get | Benefit | Cost |
|---|---|---|
| Goroutines | Concurrency cheap enough to use freely — each starts with about 2 KB of stack and grows on demand | A scheduler between you and the OS, and leaks that no compiler will catch for you |
| Garbage collection | No manual memory management, no use-after-free | Pauses you do not control, and allocation costs that only a profiler reveals |
| Static binaries | Deploy one file, no runtime to install | Larger artifacts than an interpreted language ships |
| Implicit interface satisfaction | Packages compose without importing each other | The compiler cannot tell you what a type was *meant* to satisfy |
| A small language | The whole spec fits in an afternoon; unfamiliar code stays readable | Verbosity where other languages would give you a shortcut |

> 💡 Real-world example
>
> Kubernetes, Docker, Prometheus, etcd and Terraform are all written in Go. That is not a coincidence: each is a long-running networked service that has to ship as a single binary, handle many connections at once, and stay readable across a large contributor base — exactly the shape Go was designed for.
