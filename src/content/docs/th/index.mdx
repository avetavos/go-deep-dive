## ยินดีต้อนรับสู่ Go Deep Dive

คอร์สนี้สอน Go ในเชิงลึก — บนพื้นฐานของภาษา Go เอง ไม่ใช่การเปรียบเทียบกับภาษาอื่น คุณจะเรียนรู้โมเดล concurrency แบบ CSP, type system ที่เข้มแข็ง, และ toolchain ที่ครบครัน ซึ่งทำให้ Go เป็นภาษาที่เลือกใช้สำหรับระบบ production ที่ต้องการประสิทธิภาพสูง

## ทำไม Go?

| Feature | Benefit | Cost |
|---------|---------|------|
| goroutine | lightweight concurrency (2-8 KB stack) | scheduler overhead |
| GC | ไม่ต้อง manage memory เอง | GC pause latency |
| static binary | deploy ง่าย ไม่มี dependency | binary size ใหญ่กว่า interpreted lang |
| interface | implicit satisfaction, decoupled design | dynamic dispatch cost |
| no generics (pre-1.18) | simplicity | code duplication |

> 💡 Real World Example
>
> **Kubernetes** เขียนด้วย Go ทั้งหมด — goroutine หลักแสนตัวจัดการ pod lifecycle พร้อมกัน
>
> **Docker** ใช้ Go สำหรับ container runtime — memory-efficient และ deploy เป็น single binary
>
> **Prometheus** ใช้ Go สำหรับ time-series collection — goroutine pool รับ metrics จาก target นับพัน
>
> **etcd** ใช้ Go สำหรับ distributed key-value store — channel และ mutex ทำให้ consensus algorithm ปลอดภัย
